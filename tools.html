    02 / FROM DRAFT TO DOCUMENT

    Markdown to PDF

    Write on the left, see the finished page on the right. Then print or save it as a PDF.

    NO UPLOADS

    PAGE PREVIEW A4 / PRINT READY

    Your document preview will appear here.

    In the print dialog, choose “Save as PDF” (or your device’s PDF option). Headings, lists, tables, quotes, and code blocks are supported. Remote images and raw HTML are disabled. This draft stays here until you leave or reload; save the .md file to keep it.

    Use the text notes field below if your browser does not support drawing.

    04 / GIVE YOUR LINKS A LOOK

    Link checker

    Find malformed addresses and duplicates, then try a browser availability check.

    NO PROXY SERVER

    Some sites keep their status private.

    Your browser can only read a site’s response when that site allows it. “Could not verify” means check it manually; it does not mean the link is broken.

    Availability checks contact the websites you enter. They run only when you choose “Try availability”. No login credentials are sent.

    Up to 50 links at a time. Duplicate detection ignores page fragments (#…).
