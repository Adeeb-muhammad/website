08 · Key terms and exam reminders

Important definitions

Paramagnetic: A substance with one or more unpaired electrons; attracted by a magnetic field.

Diamagnetic: A substance with all electrons paired; weakly repelled by a magnetic field.

Inner-orbital complex: In this VBT example, uses inner (n−1)d orbitals in hybridisation.

Outer-orbital complex: Uses outer nd orbitals in hybridisation.

Remember for CBSE

  • Find the oxidation state first.
  • Write the metal-ion d-configuration.
  • Identify whether the ligand is strong-field or weak-field.
  • Show electron pairing before assigning hybridisation.
  • Count unpaired electrons to state magnetic behaviour.
  • For octahedral complexes, coordination number is 6.
Scope note: This interactive model follows the Class XII NCERT-style Valence Bond Theory treatment. It is a simplified bonding model. It does not calculate magnetic susceptibility or replace the more detailed Crystal Field Theory explanation.
